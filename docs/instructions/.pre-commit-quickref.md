# Pre-commit Quick Reference Card

## Installation (First Time Only)

```bash
conda activate llm_behavior_test
pre-commit install
```

## Daily Usage

### Automatic (Recommended)
```bash
git add .
git commit -m "Your message"
# Hooks run automatically

# If auto-fixes were made:
git add .
git commit -m "Your message"
```

### Manual
```bash
# Run all hooks
pre-commit run --all-files

# Run on staged files only
pre-commit run

# Run specific hook
pre-commit run black
pre-commit run flake8
```

## Makefile Commands

```bash
make pre-commit-install  # Install hooks
make pre-commit-run      # Run all hooks
make format              # Format code (autoflake + isort + black)
make lint                # Check code (isort + black + flake8)
make check               # Run all checks (lint + pre-commit + test)
```

## Common Issues

### Files were modified
```bash
git add .
git commit -m "message"
```

### Want to skip hooks (emergency only!)
```bash
git commit --no-verify -m "Emergency fix"
```

### Update hooks
```bash
pre-commit autoupdate
```

### Clear cache
```bash
pre-commit clean
```

## What Gets Checked

✅ Large files (>1MB)
✅ Merge conflicts
✅ YAML/JSON/TOML syntax
✅ Trailing whitespace
✅ End-of-file
✅ Unused imports (autoflake)
✅ Import sorting (isort)
✅ Code formatting (black)
✅ Code quality (flake8)
✅ Security issues (bandit)

## What Gets Auto-Fixed

✅ Code formatting (black)
✅ Import sorting (isort)
✅ Unused imports (autoflake)
✅ Trailing whitespace
✅ End-of-file newlines

## Configuration Files

- `.pre-commit-config.yaml` - Main configuration
- `pyproject.toml` - Black, isort, pytest
- `.flake8` - Flake8 settings
- `.bandit` - Security scanner settings
